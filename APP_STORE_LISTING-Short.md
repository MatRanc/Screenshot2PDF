# Screenshot2PDF, short App Store copy

Same submission, shorter text. For people skimming search results, not reading
a pitch. See `APP_STORE_LISTING.md` for everything else (keywords, URLs,
review notes, etc.), only Promotional Text and Description differ here.

**Promotional Text**, max 170 chars.
```
Batch-crop a folder of screenshots and export one PDF. Set the crop once, apply it to every image. Fully on-device, no network access.
```

**Description**, max 4000 chars, but short on purpose.
```
Batch-crops a folder of screenshots and combines them into one PDF.

- Set a crop rectangle once, applied to every image
- Drag to set the crop visually, or type exact pixel values
- Reorder pages by dragging thumbnails
- Override the crop on individual images when needed

Sandboxed, no network access, no data collected. Requires macOS 14 or later.
```
